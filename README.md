# hr_hospital

Модуль розташований у корені репозиторію, тому під час клонування буде створено каталог hr_hospital, назва якого збігається з назвою модуля.

## Розподіл обмежень між ACL і ir.rule

ACL визначає, які операції група може виконувати з моделлю (наприклад, видаляти може лише адміністратор), а `ir.rule` — які саме записи їй доступні (пацієнт бачить лише свої візити, лікар — свої та своїх інтернів). ACL перевіряється першим і працює як стеля, правила лише звужують результат і ніколи не дають нових прав. Тому `perm_*` в обох шарах означають різне: в ACL вони дають право на операцію, а в правилі лише вказують, для яких операцій воно перевіряється. Наприклад, у правилі пацієнта для візитів `perm_write=False` не забороняє запис, а лише вимикає правило для запису; записати пацієнт однаково не може, бо в його ACL `perm_write = 0`.
